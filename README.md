### 🛠 Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Features**: Add/Delete tasks, Mark complete/incomplete, LocalStorage to save tasks, Fully mobile responsive
- **No frameworks**: Pure JS so you can see my core skills
